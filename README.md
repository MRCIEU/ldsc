# LDscores for ldsc regression

This repository contains (nextflow) pipelines and data to generate LDscores for LDscore regression, as described in the [wiki](https://github.com/bulik/ldsc/wiki/LD-Score-Estimation-Tutorial) of the [original ldsc software](https://github.com/bulik/ldsc), as well as the generated scores themselves. It also contains an example Dockerfile which will generate an image containing [a newer version of the software](https://github.com/CBIIT/ldsc) as well as the scores from this repository which you can use to run LDscore regression yourself.

## Using the Docker image to run ldsc

You need [Docker](https://www.docker.com/)

Clone this repository, enter it, and build the image (the docker tag below is given for example purposes):

```sh
git clone https://github.com/MRCIEU/ldsc-pop-prep
cd ldsc-pop-prep
docker build --platform linux/x86_64 --no-cache -t mrcieu/ldsc:ldsc-0448dd3-python3.13 .
```

`ldsc.py`, `munge_sumstats.py` and ` make_annot.py` are in the `PATH` so you can run, for example:

```
docker run mrcieu/ldsc:ldsc-0448dd3-python3.13 ldsc.py -h
```

or

```
docker run mrcieu/ldsc:ldsc-0448dd3-python3.13 munge_sumstats.py -h
```

To run `ldsc` for real, you can do something like:

```
docker run \
    -w /work \
    -v ${PWD}:/work \
    mrcieu/ldsc:ldsc-0448dd3-python3.13 \
    ldsc.py \
        --h2 sumstats.gz \
        --ref-ld-chr /ldscores/GRCh37/EUR/ \
        --w-ld-chr /ldscores/GRCh37/EUR/ \
        --out ldsc.h2
```

or

```
docker run \
    -w /work \
    -v ${PWD}:/work \
    mrcieu/ldsc:ldsc-0448dd3-python3.13 \
    ldsc.py \
        --h2 sumstats.gz \
        --ref-ld-chr /ldscores/GRCh37/WEIGHTED_MEAN/ \
        --w-ld-chr /ldscores/GRCh37/WEIGHTED_MEAN/ \
        --not-M-5-50 \
        --out ldsc.h2
```

Where `/ldscores/GRCh37/...` is pointing to the LDscores from this repository (see below) which were copied into the container when the image was built. Of course, you can also use your own scores by providing them and changing the path.


## Generating the LDscores

A set of scores have been generated for each of the following 1000 Genomes super-populations:

    1) AFR
    2) AMR
    3) EAS
    4) EUR
    5) SAS

Separate pipelines exist for both GRCh37 and GRCh38 human genome builds (which have slightly different input data).

The pipelines require that you download ~33GB (14GB) of 1000 Genomes data as input for GRCh38 (GRCh37). Scripts to download these data exist in this repository in `GRCh3{X}/data/download_data.sh`. Run these shell scripts before running the relevant nextflow pipeline.

88MB of precomputed information about ~1.2 million HapMap3 SNPs is already present in `GRCh3{X}/data/hm3/`, and is also required to run the pipeline. These data consist of the list of snps (labelled by RSID) (`GRCh37/data/hm3/w_hm3.snplist`), and per-chromosome tables linking snps (RSIDs) to their genomic location. These data were generated by the scripts `GRCh3{X}/scripts/get_RSID_info.R`.

Genetic map data is already present in `GRCh3{X}/data/map/`. For GRCh38 the map data (in `GRCh38/data/hm3/map`) was obtained, then derived, from [Halldorsson et al. 2019](https://www.science.org/doi/10.1126/science.aau1043). For GRCh37 the map data is from [here](https://mathgen.stats.ox.ac.uk/impute/1000GP%20Phase%203%20haplotypes%206%20October%202014.html).


## Additional multi-ancestry LD scores

There is R code in the `GRCh3{X}/scripts/` folder to generate LD scores based on the mean values from the AFR AMR EAS EUR and SAS populations' scores. 

## Running the pipeline to generate the scores

The various software the pipeline needs must be already available to you locally. Then:

```
nextflow run main.nf
```

Optionally, you can set the sample size to (randomly) subset the populations to, prior to calculating LDscores, and specify the name of the directory to write the results to:

```
nextflow run main.nf --n 100 --results_dir output
```

If you don't set these options, their defaults are n=300 and results_dir=results

## Output

The (per-chromosome) LDscores are written to 

```
{results_dir}/
    ldscores/
        AFR/
        AMR/
        EAS/
        EUR/
        SAS/
```

And the sample lists retained after subsetting the data to `n` individuals for each population are written to

```
{results_dir}/sample_lists/{POP}.samples.tsv
```

## Multi-ancestry scores

Once you have run the pipeline you can run the code in `GRCh3{X}/scripts/make_mean_ldscores.R` which will create:

```
{results_dir}/
    ldscores/
        MEAN/
        WEIGHTED_MEAN/
```

`MEAN/` contains the arithmetic mean of the scores for the AFR AMR EAS EUR and SAS populations, at sites which are present in every population's individual LD scores.

`WEIGHTED_MEAN/` contains the arithmetic mean weighted by the samples sizes as they are in the UK Biobank.

The results for the mean LD scores only contain the `{chr}.l2.M` files, not the `{chr}.l2.M_5_50` files, so to use them you will need to pass the `--not-M-5-50` flag to `ldsc.py`.

## Plots

Per chromosome plots of the scores are available in `GRCh3{X}/scripts/plot_LDscores.html`. The shaded area on chromosome 6 is roughly the extended HLA region.

## Notes

Related samples (as defined in `GRCh38/data/vcf/20130606_g1k_3202_samples_ped_population.txt` and `GRCh37/data/vcf/20140625_related_individuals.txt`) are removed prior to choosing samples for inclusion in the LD calculations.
